# TrackScape 🛡️⚔️

TrackScape is a lightweight, mobile-optimized planning console built specifically for Free-to-Play (F2P) Old School RuneScape players. It combines dynamic leveling guides, precise bestiary kill calculators, multi-skilling synergy routes, and stat auto-detection into a single, responsive web app.

## ✨ Features

- **Full F2P Bestiary Database:** Contains every F2P monster from Level 1 Rats to Level 120 Obor.
- **Smart Searchable Dropdowns:** Scroll through the bestiary or type to instantly filter your target monster/resource.
- **OCR Stat Auto-Detection:** Upload a screenshot of your OSRS skills tab, and TrackScape will automatically scan and input your current levels using client-side Tesseract.js.
- **All 15 F2P Skills Supported:** Calculate precise actions needed for Combat, Gathering, and Artisan skills.
- **Multi-Skilling Synergies:** Discovers efficient combos (e.g., burn-as-you-cut Woodcutting/Firemaking or mine-and-superheat workflows).
- **Mobile-First UI:** Designed with vertical stacking and large touch targets to eliminate layout bugs on phones.

## 🛠️ Installation & Hosting

This app runs entirely in the browser using HTML, CSS, and vanilla JavaScript. No backend server is required!

1. Clone or download this repository.
2. Open `index.html` in any modern web browser to run it locally.
3. **To host for free via GitHub Pages:**
   - Go to your repository **Settings** -> **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Set the branch to `main` (folder: `/root`) and click **Save**.
   - Your site will be live in a few minutes!
